Weekday plan

The default week. Each slot has a role (what kind of post), a format and the template that renders it. Even ISO weeks add the Week B rotation noted under each day.

Campaigns & overrides

A campaign is a date range with an instruction the overnight run follows instead of, or on top of, the weekday plan: Ramadan mode, school holidays, the 2027 registration push. Newer campaigns win when two overlap.

Registered templates

a template is a Canva design whose text boxes the pipeline knows how to fill

Add a template

Text boxes in the design should hold placeholder text like {{COVER_TITLE}}, {{S2_TITLE_A}}, {{S2_BODY}} … so the mapping run can find them. If a box is missing, the run tells you which one here.

Ask for a new design

The next hourly run drafts it in Canva from the brand kit and lists it here as "draft · tidy in Canva". Open it, fix anything by hand, then press "Map text boxes" to make it live.

Clone a post's style

structure and formatting only, rebuilt in LQK colours and fonts

Paste the link to an Instagram or TikTok post whose layout you like and drop a screenshot or two. The next hourly run reads how the post is built — grid, text hierarchy, slide order, caption shape — rebuilds that structure as an LQK-branded Canva design, and registers it in Templates ready to use on any slot. None of the original artwork, photos, fonts or wording is copied: only the skeleton comes across, dressed in LQK colours.

Instagram and TikTok block automated reads, so the screenshots are what the run actually looks at.
